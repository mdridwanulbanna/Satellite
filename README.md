# Colab notebooks

These notebooks ran Steps 1 to 5 on Google Colab during the study. Each one installs the packages, takes the
`nbob_sst_study` code as an uploaded zip, asks for the user's own login where a data portal needs one (Copernicus
Marine, NASA Earthdata) and saves the outputs. No login details are stored in the notebooks. Lines such as
"send it back in the chat" refer to how the results were passed on during the analysis and can be ignored.

| Notebook | Step |
| --- | --- |
| Step1_L4_uncertainty_Colab.ipynb | Step 1b: L4 station series |
| Step1c_L4_uncertainty_Colab.ipynb, Step1c_v2_L4_uncertainty_Colab.ipynb | Step 1c: L4 analysis uncertainty (v2 is the version used) |
| Step2_iQuam_scoping_Colab.ipynb | iQuam drifter scoping, 2018-2020 |
| Step4_L3_download_Colab.ipynb | Step 4: L3 subsets for MetOp-B, Aqua and Terra |
| Step5_reliability_Colab.ipynb | Step 5: reliability metrics (RQ1) |
| Step5b_accuracy_fallback_Colab.ipynb | Step 5b: 2016-2017 accuracy fallback |
